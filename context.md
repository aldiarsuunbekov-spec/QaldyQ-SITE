# 🍏 QaldyQ — Контекст проекта для хакатона

> **Save food. Save money. Every bite counts.**  
> Платформа для минимизации пищевых отходов (Food Waste) в заведениях общественного питания Казахстана.

---

## 🚀 О проекте
**QaldyQ** (от каз. *қалдық* — остаток, отход) соединяет кафе, пекарни, кофейни и супермаркеты с покупателями, которые хотят приобретать качественную свежую еду по доступной цене в конце рабочего дня. Заведения возвращают часть выручки со списаний, а покупатели экономят бюджет и берегут ресурсы планеты.

---

## 🛠 Технологический стек (Tech Stack)
* **Frontend:** HTML5, CSS3 (Vanilla с кастомными дизайн-токенами и переменными), JavaScript (ES6+).
* **Интерактивные карты и геолокация:** Leaflet.js, OpenStreetMap (Overpass API для динамического поиска точек рядом).
* **Архитектурные особенности:**
  * Полностью адаптивный интерфейс (Mobile-First, поддержка экранов от 320px до 4K).
  * Локальное хранение данных (`localStorage` / `sessionStorage`) для броней, корзины и профиля покупателя.
  * Безопасная клиентская и серверная логика (хеширование паролей, CSRF-токены, сессии).

---

## 📱 Ключевой функционал MVP
1. **Каталог предложений:** Фильтрация по городам Казахстана (Алматы, Астана, Шымкент и др.), категориям (пекарни, готовая еда, кофейни, десерты) и времени самовывоза.
2. **Интерактивная карта:** Отображение предложений и кафе по геокоординатам, определение расстояния «Рядом со мной».
3. **Корзина и бронирование:** Пакетное оформление броней, генерация уникальных номеров заказов, отправка уведомлений/шеринг в WhatsApp.
4. **Кабинет партнера (для бизнеса):** Авторизация заведений, публикация наборов, интеграция с AI-прогнозом остатков и контроль активных заказов.
5. **Интерактивные фичи:** Слепые эко-боксы, автоматический *Flash Drop* (снижение цен перед закрытием) и дашборд сэкономленной еды и средств.
